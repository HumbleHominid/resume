My course work has a similar split between engineering and analysis.
For a team project on traffic accidents in Frankfurt, I built the Streamlit dashboard on my own and wrote most of the data pipeline (150 of the project's 164 commits).
I've since extended it to all of Germany: it clusters about 2.4 million injury accidents from 2016 to 2025 with DBSCAN, and residents can pick any of the 401 districts.
The default cluster size is tuned per district by binary search, and in Frankfurt it finds hotspots such as the Hauptbahnhof area and the A661.
This semester I also built \textit{Agentic Connections} for my Strategy \& Performance Management course, an LLM agent on the Anthropic API that plays NYT Connections and reports its own score.
Over 300 pre-registered runs, the code checked every report against the game's ground truth.
